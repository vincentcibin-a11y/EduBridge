# EduBridge Screenshot Evidence

This page provides a visual index of the screenshot previews associated with EduBridge's manual acceptance testing.

> **Evidence integrity:** These previews are GitHub-hosted attachments embedded in this document. They are not binary files committed in this directory. For a fully version-controlled evidence package, also save the original screenshots here using the filenames below. Only mark a manual test as Pass after verifying the behaviour on a running application and recording the result in [Manual Acceptance Test Evidence](../Manual_Acceptance_Test_Evidence.md).

## How to store the original files in this folder

1. Capture the relevant screen using `Win + Shift + S`.
2. Save the screenshot in this directory with the suggested filename.
3. Avoid capturing passwords, JWT tokens, secret environment variables, or personal information.
4. In the manual acceptance record, enter the actual Pass/Fail result and reference the filename.
5. If a preview above does not match the current application or cannot be verified, replace it with a fresh screenshot from the current version.
